# Langues, unités, charte, accessibilité, polices, thème

Notes détaillées de Sillage, sorties de CLAUDE.md le 23/11/2026 (texte d'origine, non résumé). Voir CLAUDE.md pour les règles générales.

## Langues (essai du 26/10/2026, en ligne le même jour)
- Français + anglais. Le code garde les textes en français ; `T('texte {0}', [valeur])` les traduit avec le dictionnaire `lang.js` (`window.PMR_I18N.en`, clé = texte français exact, `{0}`, `{1}`… = valeurs), chargé par `<script src="lang.js">` juste avant le script principal. Sans traduction, `T` rend le français. Les variables locales qui s'appelaient `T` sont devenues `TT` (elles masquaient la fonction).
- Langue : `LANG` = `localStorage` `pmr-lang`, sinon celle du navigateur (`fr…` → français, tout le reste → anglais) ; `LOC` = `en-GB` / `fr-FR` pour toutes les dates et nombres (`Intl.DateTimeFormat(LOC…)`, `toLocaleString(LOC)`, tri `localeCompare(…, LANG)`), `<html lang>` mis à jour. HTML fixe traduit au chargement par `i18nDom(document.body)` (nœuds de texte et attributs `placeholder` / `title` / `aria-label` / `alt`, clé = texte aux espaces ramenés à un seul ; pas d'espace avant une traduction qui commence par « : »). Onglet « Parcours » du bas = « Routes » (pluriel, forcé à part).
- Choix : page Moi, carte « Affichage », « Langue » `#meLang` (Français / English) ; écran de connexion, lien `#gateLang` vers l'autre langue. `setLang(l)` enregistre, met à jour `push_alerts.lang` si connecté, puis recharge la page.
- Particularités en anglais : boussole avec W au lieu de O (`COMPASS`), heures des graphes « 9:00 » au lieu de « 9h » (`hrTxt`), en-têtes du CSV en anglais, noms des fonds de carte traduits (`T('Plan (OSM)')`… : `pmr-base2` garde le nom affiché, un changement de langue revient au fond par défaut). Jours des alertes (`AL_DAYS` / `AL_DAYN`) tirés d'`Intl`.
- Ajouter un texte : l'écrire en français dans `T(...)` (ou dans le HTML) et ajouter sa traduction dans `lang.js`. Ajouter une langue : un objet dans `lang.js`, la mettre dans `LANGS`, `LOC` et `#meLang`, et dans `push-alerts` (`LANGS`, dictionnaire, contrainte de `push_alerts.lang`).
- Alertes : colonne `push_alerts.lang` ('fr' | 'en', défaut 'fr', écrite par `alSave` et `setLang`) ; `push-alerts` (version 2, 26/10/2026) écrit titre et texte dans cette langue (`tr(lang, …)` et dictionnaire `EN` de `forecast.ts`, `verdict(s, lang)`).
- Pas traduits : `admin.html` / `admin-test.html` (pour l'admin), noms de lieux d'OpenStreetMap, durées « 1 h 23 ». **Mise en ligne** : copier aussi `lang.js` (déjà à la racine, partagé par index.html et test.html).

## Unités (essai du 26/10/2026, en ligne le même jour)
- Tout reste calculé et gardé en km, m, km/h, °C et mm (simulation, seuils, parcours, alertes) ; la conversion se fait seulement à l'affichage. Deux réglages indépendants dans Moi, carte « Affichage » : « Distances et vitesses » `#meDist` (Métrique (km) / Impérial (mi) : km → mi, m → ft, km/h → mph, m/h → ft/h, mm → in) et « Température » `#meTemp` (°C / °F). `localStorage` `pmr-units` = { dist: 'km' | 'mi', temp: 'c' | 'f' } ; sans choix : impérial pour un navigateur en-US / en-GB, °F pour en-US. `setUnits(ch)` enregistre, met à jour `push_alerts.dist` / `temp` si connecté, puis recharge la page.
- Code : `UNITS` { mi, f } et libellés `UL` (km, m, kmh, mh, mm, mmh, C) définis juste après `LOC` ; conversions `uD` / `uE` / `uV` / `uT` / `uR` ; valeurs prêtes à afficher `fD(km, décimales)`, `fE(m)`, `fV(kmh, décimales)`, `fT(°C)`, `fR(mm)` (2 décimales en pouces), `fOff(m)` (écart à la trace). Dans `T`, `unitTpl` remplace l'unité seulement quand elle est collée à une valeur (« {0} km », « km {1} », « {2} °C ») ou entre parenthèses (« (km/h) ») : **toute valeur passée à côté d'une unité dans `T` doit passer par fD / fE / fV / fT / fR**. Les unités écrites en dur hors de `T` utilisent `UL`. Textes fixes du HTML (en-têtes « Km », légendes « (mm/h) », « < 4 km/h », titres « au fil des kilomètres », rayon des ravitos) adaptés au chargement juste après `fOff`.
- Graphiques : repères ronds dans l'unité affichée (altitude du profil `eK`, températures `tBack`, axe des distances du profil et des graphes du jour `kK`) ; pastilles de la carte et export image en mph / °F. Le CSV reste en métrique (en-têtes avec unités). Les descriptions des modèles météo (« maille de 2 km ») restent en km.
- Alertes : colonnes `push_alerts.dist` ('km' | 'mi') et `temp` ('c' | 'f') ; `push-alerts` version 3 (26/10/2026) : `unitsOf`, `cv` et `tr(lang, k, a, u)` dans `forecast.ts`, `verdict(s, lang, u)`.

## Accessibilité (28/10/2026, en ligne directement dans index.html et test.html)
- Page Moi, carte « Affichage » : « Couleurs » `#meCvd` (Standard / Daltonisme rouge-vert `deutan` / Daltonisme bleu-jaune `tritan` / Contraste élevé, noir et blanc `mono`), avec un aperçu (vent de dos, vent de face, pastilles) ; « Animations » `#meMotion` (Normales / Réduites `reduce`) ; « Police » `#meFont` (Sillage (Archivo) / Très lisible `hyper` = Atkinson Hyperlegible, Google Fonts chargée à la demande ; pas embarquée dans l'app : repli sur la police système hors ligne).
- `localStorage` `pmr-a11y` = { cvd, motion, font } ; appliqué en tête de `<head>` (deuxième petit script, dans une fonction) : `html[data-cvd]`, `html[data-motion="reduce"]`, `html[data-font="hyper"]`. `a11ySet` enregistre puis recharge la page (les échelles de couleur du script sont fixées au chargement) et rouvre Moi (`sessionStorage` `pmr-open-me`).
- CSS : chaque palette redéfinit `--tail`, `--head`, `--warm`, `--rain`, `--cross` (et en `mono` fond, encre, lignes, accent), plus les niveaux `--lv0` / `--lv1` / `--lv2` (pastilles `.vdot`), `--lv0t` / `--lv1t` / `--lv2t` (textes `.vtxt`) et `--mid` (pastille orange de Mes sorties). Règles sombres à spécificité plus forte (`:root[data-theme="dark"][data-cvd]`, et dans `prefers-color-scheme:dark`) : elles redonnent toutes les variables des règles claires. Teintes : Okabe-Ito bleu / orange / jaune pour `deutan`, sarcelle / rose / rouge pour `tritan`, gris pour `mono`.
- Script : `CVD` (lu sur `<html>`), `WIND_COLS[CVD]` → `WIND_SCALE` (flèches, vent animé, rose, légende), `TEMP_SETS[CVD]` → `TEMP_STOPS`, rampe de pluie grise en `mono`, `EXP_CVD` complète `expPal` (export image). `reducedMotion()` = réglage de l'app ou de l'appareil (vent animé figé) ; `html[data-motion="reduce"]` coupe transitions et animations CSS.
- Pas de réglage de taille du texte : les tailles sont en px partout et un `zoom` CSS risquerait de décaler la carte Leaflet ; à reprendre si besoin.

## Polices

- Depuis le 14/10/2026 (en ligne le 17/10/2026) : Bricolage Grotesque (`--f-display` : titres, onglets, étiquettes, résumé, chiffres des tuiles), Manrope (`--f-body`), IBM Plex Mono (`--f-mono`), via Google Fonts. ## Thème
- Choix en haut de page « ☀︎ / Auto / ☾ » (`#themeSeg`, `setTheme`) : `data-theme` = `light` / `dark` sur `<html>`, ou rien en automatique (suit l'appareil). Gardé dans `localStorage` `pmr-theme`, appliqué par un petit script en tête de `<head>` (pas de flash). Les dessins canvas (profil, carte, graphes du jour) sont refaits au changement (`redrawTheme`).
